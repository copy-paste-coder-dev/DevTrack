# Changelog

## 0.1.0 — release candidate, 2026-10-14

- Google authentication, protected routes and user-scoped Firestore activities/preferences.
- Daily logging with smart times, overlap checks, gaps, targets and calendar analysis.
- Keyboard entry, duration/type shortcuts, recent tasks, duplicate/repeat and local filters.
- Responsive dark workspace, keyboard dialogs/menus and automated accessibility checks.
- Hardened activity validation, Firebase Hosting configuration and production preview/emulator regression checks.

The candidate was published to [dev-track-46323.web.app](https://dev-track-46323.web.app) on October 14 using the Firebase project explicitly selected by the user. Hardened rules/indexes are deployed, Google/domain configuration is verified, and public deployment/guest checks pass. No existing user data was changed. Final acceptance remains subject to the [live-account checklist](docs/RELEASE_CHECKLIST.md); see the [deployment record](docs/RELEASE_0.1.0.md).
